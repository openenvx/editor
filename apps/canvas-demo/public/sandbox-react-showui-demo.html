React-in-showUI (reference)

Sandbox extensions may ship React (or any UI framework) inside showUI HTML. Studio never mounts author React in the editor main world. See packages/workbench/src/sandbox/fixtures/react-showui-demo.ts for the runnable fixture used by tests (tiny createElement/useState runtime — production authors bundle real React the same way).

Duplex contract:

  • Iframe → isolate: postPluginMessage(msg) → openenvx.ui.onmessage
  • Isolate → iframe: openenvx.ui.postMessage(msg) → onPluginMessage
  • Host → iframe: ui:context (theme; selection only with document:read) → onPluginContext

Demo grant HTML/source lives at packages/workbench/src/sandbox/fixtures/react-showui-demo.ts (test/fixture import — not a workbench public export).
